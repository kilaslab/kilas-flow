# web-editor

- 2026-09-05: A Svelte 5 $effect that both reads and writes a piece of $state is a live infinite loop, not a lint nit. The version panel's publish-timeline effect read events.length and loadingEvents and also wrote both: for a workflow whose publish history is EMPTY the fetch resolved to [] and re-satisfied the effect's own guard forever. The load-once flag must be a plain 'let' the effect does not track, not $state. Watch for this shape anywhere a component lazily fetches a list that can legitimately come back empty. (cites: web/src/lib/components/workflow-editor/version-panel.svelte)
- 2026-09-05: Publishing an older workflow revision does NOT remount the editor, verified rather than assumed: publish() in internal/repository/workflows.go issues Updates({active, active_version_id}) and never touches latest_revision, so the {#key currentWorkflow.latestVersion.id} wrapper in both editor hosts is unchanged and an unsaved canvas survives a publish. Restore DOES append a revision and therefore does remount, which is why the version panel refuses to restore while the canvas is dirty. Any future operation that writes latest_revision silently gains the power to discard a user's unsaved work.
- 2026-09-05: To show a historical revision on the workflow canvas, draw it BESIDE the draft, never into it: workflow-editor.svelte keeps a 'preview' state and the canvas projection reads (preview?.document ?? draft), with one 'locked' flag (readOnly || previewing) gating every mutation, the toolbar, the canvas and the inspector. Loading a version into the draft and putting it back afterwards is the same work with an extra way to lose the user's unsaved edits. 'preview' is bound between the editor and the version panel so the canvas banner and the panel clear one variable; an earlier version kept a separate 'selected' in the panel and desynced the moment the banner was used.
- 2026-09-21: A manual run that omits triggerNodeId fires every root with an empty item. When kilasflow.chatTrigger is on the canvas, Execute must always name a non-chat trigger, or open the Chat panel on a chat-only graph — omitting the id would still run chat with {}. (cites: web/src/lib/workflow-editor/run-trigger.ts)
- 2026-09-21: Keep the canvas Chat panel mounted (hidden) while the chat trigger is on the document. Unmounting on Close recreates sessionId and wipes history; New chat is what rotates the id. (cites: web/src/lib/components/workflow-editor/workflow-editor.svelte)
- 2026-10-09: A resourceMapper that sets modelDefinable (the Workflow Tool's workflowInputs) stores a column left to the model as one whole $fromAI call, and a column with no entry is the model's too; any other present value, null included, is fixed. Go (ai.WholeFromAICall, nodes.WorkflowToolInputs) and TypeScript (isModelDefined in resource-mapper.ts) must keep this one rule, and an n8n import stores an untouched schema column as an explicit null to keep it out of the model's schema. (cites: web/src/lib/workflow-editor/resource-mapper.ts, nodes/ai.go)
- 2026-10-08: The execution replay node (web/src/lib/components/workflow-editor/execution-canvas-node.svelte) renders ports separately from the editor's canvas-node.svelte: any change to resolvedPorts or to port-label placement must be mirrored there, or the replay silently drops edges whose handle it does not draw (BUG-sgrxhh's error branch did exactly this). web/ has no Svelte component test harness, so keep that logic in pure helpers and check the replay in the running app.
- 2026-10-08: The version-history Sheet is an overlay docked to the window's right edge, not a grid column like the inspector, so anything that frames the canvas while it is open (fitView on preview start/end) must pad by the panel's measured overlap: fitView accepts per-side px padding ({right: '440px'}), see fitPaddingBeside in web/src/lib/workflow-editor/save-feedback.ts. The inspector, by contrast, shrinks the canvas itself, so a selected node is revealed with setViewport against canvasRegion's own size (viewportRevealing in canvas-chrome.ts), never setCenter, whose width Svelte Flow learns a ResizeObserver later.
- 2026-10-09: A CSS custom property that references another one resolves WHERE IT IS DECLARED and is inherited as that computed value. So an alias declared only on :root (`--primary: var(--kf-accent)`) keeps the dark/default value inside a `[data-theme='light']` or `[data-kf-brand]` subtree, and a Tailwind `@theme` colour entry (`--color-primary: var(--primary)`) without `inline` is resolved once at :root the same way, which is why the embed's old `--primary` override never recoloured `bg-primary`. web/src/app.css therefore declares every derived and alias token on `:root,[data-theme],.theme-dark,.theme-light,[data-kf-brand]` and maps colours with `@theme inline`; a new alias or `--color-*` entry must follow both rules, and markup must not read `var(--color-*)` (unused ones are not emitted under inline). tokens.groups.test.ts checks the boundary list. (cites: web/src/app.css)
- 2026-10-09: web/src/lib/workflow-editor/ports.ts `resolvedPorts` mirrors Go `PortsFor` by hand for switch, merge, datastore, the two vector stores and the embeddings node (BUG-pc284d). The vector-store and embeddings mirror is held to nodes/testdata/ports_for.golden.json, which `go test ./nodes -run TestPortsForGolden -update-ports-golden` rewrites from the registry and ports.golden.test.ts reads; the same Go file's census test fails when a registered node resolves ports in Go with no editor case, so a new PortsFor node must get a ports.ts case (or be named in portsGoldenMirroredByHand). The imported RAG fixtures' real documents live in internal/interop/n8n/testdata/imported_ports.golden.json (`-update-imported-ports-golden`) and ports.imported.test.ts checks every edge has both handles. Mirror Go quirks, do not tidy them: the typed vector-store ports apply when the `mode` KEY exists even if empty or null, and a "GETMANY" mode resolves to plain main ports on the server. A tile's shape (nodeShape) takes the resolved ports, not the static ones, or a retrieve-mode store is drawn as a step whose attachment labels overprint its name. (cites: web/src/lib/workflow-editor/ports.ts, nodes/ports_for_golden_test.go)
