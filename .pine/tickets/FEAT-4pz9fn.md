# Description

The revamp needs one place where contributors, embed hosts and reviewers can see the system. It should cover: - the thesis ('turmeric shows only where you act'); - both palettes with their contrast pairs; - the measured competitor exclusion zones (n8n coral, orange and pink-red; qonflo.ai violet, magenta and cyan); - the category and run-state ramps, the type scale, and the motion and density specs; - do/don't examples: no brand-tinted or purple-tinted surfaces, no gradients, no per-node hex, no amber warning beside turmeric, no mono as decoration. It also becomes the source for embed hosts choosing --kf-accent-src.

# Acceptance Criteria
- [ ] A docs page (Starlight, docs/src/content/docs/…) or a dev-only /app/_design route renders every --kf-* token as a swatch in both themes, generated by parsing web/src/app.css at build time (no hand-copied values).
- [ ] The page shows the contrast table produced by the VR-01 contrast test, and CI fails if the table and the tokens disagree.
- [ ] It includes live examples of the 6 categories, 7 run states, badges, focus ring, selection, edges and the motion tokens (with a reduced-motion preview).
- [ ] It documents the embed accent rule: the minimum contrast an --kf-accent-src must meet, and how the derived steps are computed.
- [ ] It shows the exclusion-zone table from audit §6.1, with swatches and OKLCH hues, next to the Kunyit accent and its measured hue distances.

# Implementation Plan

Prefer the docs site so embed hosts can read it. The page doubles as the fixture page for the VR-03 harness.
