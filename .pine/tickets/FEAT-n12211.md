# Description

A host's own pack must authenticate against the host API with a named credential type, for example "Acme API" with a non-secret `baseUrl`, a secret `apiKey`, a header placement and a test request. Today packs can only name built-in types (`docs/src/content/docs/concepts/credentials.md:159-205`: "A pack cannot contribute one today"), although the Go registry is already open (FEAT-2f68r8).

# Acceptance Criteria
- [ ] The pack manifest accepts `credentialTypes[]` with `{id, displayName, fields (property language, secret and masked flags), authenticate (placement descriptor), test}`.
- [ ] Ids are namespaced to the pack and immutable once released.
- [ ] `nodepackgen validate` checks the new block.
- [ ] The types appear in `GET /credential-types` and work in routing and lifecycle requests.
- [ ] The credentials doc is updated.
