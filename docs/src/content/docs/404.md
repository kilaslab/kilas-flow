Nothing lives at that address. The page may have moved, or the link may have
been mistyped. Internal links on this site are checked on every build, so a
broken link between two of its pages should not be possible. A link that came
from somewhere else is the likelier cause.

Start from one of the three tracks:

- [Embed in your SaaS](/guides/saas-playbook/): mount the editor, map customers
  to tenants, keep keys on your backend.
- [Integrate via API](/guides/trigger-workflows/): start runs and events from
  your backend and read the results.
- [Build nodes for your API](/guides/build-nodes-for-your-api/): ship your
  product's API as workflow nodes.

The search box in the header covers every page, and the sidebar has the full
structure. The repository is at
[github.com/kilaslab/kilas-flow](https://github.com/kilaslab/kilas-flow), where
the `README.md` describes how to build and run it.
